Cómo grabar para un buen análisis
  • De perfil (cámara a tu lado, perpendicular a la dirección del golpe).
  • Cuerpo entero visible, de pies a cabeza, durante todo el golpe.
  • Cámara fija a 3–6 m, a la altura de la cadera.
  • Un solo golpe por video, de 3 a 10 segundos. Si puedes, a 60 fps.
  • Buena luz; evita contraluz.
